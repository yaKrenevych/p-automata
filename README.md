# P-Automata Free Group Analysis

This repository contains Python scripts for analyzing properties of groups generated by finite p-automata, specifically focusing on free groups defined by p-automata as described in related research. 

The scripts implement generalized Mealy automata to apply group elements (reduced words) to strings (words over a finite alphabet) and provide tools to count fixed words and find minimal non-fixed words using dynamic programming and breadth-first search (BFS).

## Overview

The code implements two specific finite p-automata, **Automaton A** and **Automaton B**, over an alphabet of size $p$. These automata generate a group, and the scripts allow for applying elements of this group to words. The core functionality includes:

*   **Automaton Implementation:** `AutomatonA` and `AutomatonB` inherit from a base `MealyAutomaton` class[cite: 3]. They define state transitions (psi) and output functions (lam), specifically implementing the rule where only states #5 and #10 modify the input character by $(x-1) \pmod p$ or $(x+1) \pmod p$[cite: 3].
*   **Word Generation & Application:** Functions to generate random reduced words representing group elements ($g$) and apply these elements (or their inverses) to words over the alphabet[cite: 3].
*   **Fixed Word Counting:** Calculating how many words of a given length $n$ remain unchanged (fixed) after applying a group element $g$[cite: 3].
*   **Minimal Non-Fixed Word Search:** Finding the shortest word that is altered by a given group element $g$ using a BFS approach.

## Files

*   **`t_01.py`**: The standard implementation for analyzing the automata. It uses an iterative, brute-force approach (`itertools.product`) to count fixed words[cite: 3]. Useful for smaller lengths ($n$) or when generating all explicit fixed words is necessary.
*   **`t_01_fast.py`**: An optimized version of the analysis script. It introduces two major improvements over `t_01.py`:
    *   **Recursive DP with Memoization (`count_fixed_recursive`)**: Significantly speeds up the counting of fixed words for larger lengths ($n$) by caching intermediate states[cite: 4].
    *   **BFS Search (`find_minimal_non_fixed_word`)**: Efficiently finds the shortest possible word that a given group element $g$ changes (where $g(w) \neq w$)[cite: 4].

## Core Components

### `SigmaModP`
A helper class that precomputes modular arithmetic mapping for the alphabet characters ($x \to (x-1) \pmod p$ and $x \to (x+1) \pmod p$) to avoid runtime type conversions[cite: 3].

### `MealyAutomaton`
The base class defining the structure of the automata[cite: 3].
*   **`lam` / `lam_inv`**: The output functions. They modify the character only if the automaton is in state `5` or `10`[cite: 3].
*   **`psi` / `psi_inv`**: The transition functions determining the next state based on the current state and input character[cite: 3].

### `AutomatonA` & `AutomatonB`
Concrete implementations containing the specific transition tables (`build_transition_table_A`, `build_transition_table_B`) and their inverses[cite: 3].

### Analysis Functions

*   **`count_fixed_words(g, n, p, A, B)`** (`t_01.py` & `t_01_fast.py`): Iterates through all possible words of length $n$ and counts how many satisfy $g(w) = w$.
*   **`count_fixed_recursive(n, p, g, A, B)`** (`t_01_fast.py`): A faster, memoized recursive approach to count fixed words. It tracks the collective states of the entire sequence of automata defined by $g$[cite: 4].
*   **`find_minimal_non_fixed_word(g, p, A, B)`** (`t_01_fast.py`): Uses BFS to find the shortest string $w$ such that applying $g$ modifies at least one character[cite: 4].
*   **`build_w_from_g(g, p)`**: Synthesizes a specific test word $w$ based on the structure of the group element $g$, mirroring constructions used in mathematical proofs[cite: 3].
