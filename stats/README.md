# t_01 — Обчислення статистики для комбінацій групових елементів

Цей проєкт виконує генерацію та статистичний аналіз послідовностей з елементів групи (наприклад, `('a', 1)`, `('b', -2)` тощо).  
Вивід містить кількість фіксованих слів для кожної комбінації.

# Структура проєкту
├── t_01.py # Основний Python-скрипт
├── statistics_n7_2000_L10_MAX3.txt # Приклад файлу з результатами
└── README.md # Документація проєкту

# Вхідні дані, редуковане слово генерується рандомно.
# Вихідний приклад:
g = [('a', 1), ('b', 1), ('a', 1), ('b', -2), ('a', 1), ('b', -1), ('a', -2), ('b', 2), ('a', 2), ('b', 3)] n=7, fixed words = 2133

де g — послідовність генераторів та степенів; n — розмір групи (або інший параметр задачі); fixed words — обчислене значення кількості фіксованих слів, де w = g(w).
Результати зберігаються у .txt файлі для подальшого аналізу.
